What does ThreatLens do?

ThreatLens helps analyze security logs and PDF reports to identify suspicious activity. It detects brute-force attacks, compromised login behavior, suspicious IP addresses, web scanning activity, and maps findings to MITRE ATT&CK techniques.

It also enriches suspicious IPs with AbuseIPDB threat intelligence and generates downloadable SOC investigation reports.

1. Upload

Upload .log, .txt, or text-based PDF reports.

2. Analyze

ThreatLens checks for suspicious security patterns.

3. Extract IOCs

IP addresses and user accounts are extracted automatically.

4. Map MITRE

Findings are mapped to MITRE ATT&CK techniques.

5. Check Reputation

Public IPs are enriched using AbuseIPDB.

6. Report

Generate PDF reports and CSV IOC exports.
